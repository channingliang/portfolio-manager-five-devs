# 组合管理器培训项目

## 概述

您的团队面临设计一个应用来管理金融组合的挑战。

该组合可能包含部分或全部股票、债券、现金等。

您的任务是构建该应用。

## 技术目标

您应当构建一个组合管理 REST API。这将是培训周学习 API 时的主要目标。

此 API 应允许保存和检索描述金融组合内容的记录。

当您在核心需求上取得进展后，将提供进一步增强的需求。这些需求将包含开放式增强，您可以利用个人技能和经验进行扩展。

我们将在开始学习 Web 前端的那一周继续推进此项目。

对于前端，您可以使用培训中学到的技术。如果您希望使用特定框架或其他技术，请与您的导师确认。

前端应支持用户（按优先级顺序）：

* 浏览组合
* 查看组合绩效（最好以图形方式）
* 向组合中添加项目
* 从组合中移除项目

在详细需求方面，您的导师扮演客户角色，会告诉您他们想要什么。您可以根据需求与他们安排会议。

## 注意事项

1. 不会有认证，假定单一用户，无需管理用户。
2. 对于任何持久化存储，应使用您在培训中使用的数据库技术。
3. 充分使用 Git。如果可以，使用分支和拉取请求。
4. 任何有关如何使用您的 REST API 的文档都会很有帮助。如果您在培训中学习过 Swagger，可以考虑使用它。

## 技术启动检查清单

1. 创建项目结构。
2. 创建 Git 仓库。导师会指导您使用哪个 Git 平台。
3. 将项目骨架添加、提交并推送到 Git 仓库。
4. 确保团队成员可以访问该仓库。
5. 确定第一个工作系统的绝对最少字段，例如您的模型对象的第一版可能仅包含 `id`、`stockTicker` 和 `volume`。

如果您在完成以上任何步骤时遇到困难，请联系导师寻求帮助。

## 项目管理启动检查清单

1. 团队共同决定如何开展工作。例如，2 人负责后端，1 人负责 UI 设计，或所有人先进行后端开发，直到基本系统可用。
2. 制作任务列表。理想情况下使用 Trello 等工具跟踪任务。
3. 团队中部分成员可以从事更完整功能的设计工作，同时其他成员开发一些小模块以做演示。
4. 优先选择实现最小可行版本所需的任务。
5. 导师会定期来查看进展情况。记录任何问题，以便随时提问。
6. 团队应共同决定要存储的初始数据集。良好的团队决策是成功的关键，但请保持敏捷。团队面临的最大问题往往是数据模型过于复杂。

## 成功建议

1. 从小做起。先实现一个存储非常简单对象（最少字段）的系统，然后再扩展到更复杂的记录。
2. 尝试结对编程，这通常非常有效。
3. 采取措施保持团队活力。例如，为团队起个名字，定期进行内部签到。
4. 强调质量胜于数量。

## 项目演示

在项目结束时，您将有机会向导师以及可能的经理和公司其他相关利益者演示您的项目。

演示时长由导师决定，通常 3 人小组为 15–20 分钟，大组有时可达 25–30 分钟。

### 演示指南

以下是建议流程，您不必严格遵循，但可作为大纲：

- 讲一个故事！
  - 演示应有开头、中间和结尾
- 介绍您的团队
- 介绍项目
  - 您学到了什么？
  - 您被要求做什么？
  - 您有多少时间？
- 解释项目实施方式
  - 您是否分工（后端/前端）？
  - 或是共同编码（结对编程）？
  - 使用了哪些技术和工具？
- 展示您所构建的内容
  - 从数据模型概览开始 —— 解释您的决策
  - 然后展示应用的高层架构
    - 可以是 PowerPoint 中的简单图示
  - 然后进行现场演示
- 讲述您遇到的挑战
  - 团队配合是否顺利？
  - 是否有技术挑战？
  - 您犯了哪些错误？
  - 如果重来，您会做哪些不同的事情？
- 讲述如果有更多时间，您将做什么改进
- 最后感谢聆听，并征求问题

- 每个人都应参与发言
- 演示时请保持开启摄像头
- 注意：您需要向其他团队提问

### 演示机制

* 根据班级人数，演示将在指定小组的分组讨论室中进行，由该组的主导师主持
* 主导师通常会提前制定演示日程，并以 15–30 分钟/组的形式发送给大家
* 演示不得超时，以确保准时结束
* 演示日程会发送给公司其他成员，以便他们根据日程安排观摩
* 当某组说“有问题吗？”时，为避免冷场，上一组必须提问；如果您是第一组，则最后一组必须提问
* 如果您的班级使用虚拟机，演示期间仍可继续使用

## 附录 A：团队协作说明

在本项目中，期望您密切协作。

团队应自我组织，如遇潜在阻塞，应及时向导师反馈。

团队可使用 Trello 等任务管理系统跟踪任务进度并分工。

团队应使用 Git 跟踪所有源代码。

您可以为每个组件创建单独仓库，例如前端代码一个仓库，若创建多个后端应用，每个可独立仓库。可通过单一“项目”来管理各仓库。

确保导师和团队成员均可访问所有仓库，方式为：

a) 将仓库设为公开  
b) 与导师及所有团队成员共享

保持良好沟通，定期进行团队内部签到。

## 附录 D：金融数据

您可以从雅虎获取金融数据。

### Java 项目

对于使用 Java 的同学，可参考：

https://github.com/sstrickx/yahoofinance-api

### Python 项目

对于使用 Python 的同学，可使用如下代码访问雅虎 API：

```python
import time
from datetime import datetime
import pandas as pd

dt = datetime(2023, 1, 1)
start_date = int(round(dt.timestamp()))

dt = datetime(2023, 3, 31)
end_date = int(round(dt.timestamp()))

stock = 'GOOG'

df = pd.read_csv(
    f"https://query1.finance.yahoo.com/v7/finance/download/{stock}"
    f"?period1={start_date}&period2={end_date}"
    "&interval=1d&events=history&includeAdjustedClose=true",
    parse_dates=['Date'],
    index_col='Date'
)
```

您也可以探索专门用于雅虎财经的 Python 库：https://pypi.org/project/yfinance/
