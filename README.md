### Features

1. Cash services: deposit, spend, benefit, query, logging
2. Portfolio services: buy, sell, update, query
3. Market services: query info of each part, real time price, interest rate


### Architecture

#### Frontend
- Environment: Node.js
- Framework: Vue.js
- Api Tool: axios.js
- CSS Tool: tailwindcss.js
- UI Library: Shadcn-vue, ECharts
- State Management: Pinia.js
- Linting: ESLint

#### Backend
- Environment: Node.js
- Framework: Express.js
- Linting: ESLint
- API Doc: Swagger

#### Database
- MySQL
- DB Connection: Sequelize
